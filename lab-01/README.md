### Использование программы

В качестве первого аргумента запуска программы передается путь к файлу с параметрами шифрования (по умолчанию это `results/meta.json`). Структура файла `meta.json`:

```json
{
    "algorithm": "thread|aes-ecb|aes-cbc", // required
    "source": "path",                      // required
    
    // В случае, если параметр iv не указан, то он генерируется автоматически 
    // при использовании алгоритма aes-cbc
    "iv": "string|null",

    // Если параметры не указаны, то результаты 
    // шифрования и дешифрования не сохранются
    "pathEncrypted": "path|null",
    "pathDecrypted": "path|null"
}
```
